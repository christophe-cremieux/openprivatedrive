# Security Policy Open Private Drive

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| Latest (main) | :white_check_mark: |
| Older releases | :x: |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, send a detailed report to:

**Email**: `contact@openprivatedrive.com`

### What to Include in Your Report

- Description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Any suggested fixes (if you have them)
- Affected versions (if known)

We will acknowledge receipt of your report within **48 hours** and aim to provide a full response within **7 days**.

## Security Commitments

- We take security seriously — client-side encryption and server-side permission checks are core principles.
- Files are **never** served directly from the filesystem.
- All operations go through the centralized permission engine.
- UUIDs are used instead of sequential IDs to prevent enumeration attacks.

## Responsible Disclosure

We appreciate responsible disclosure and will:
1. Investigate the issue
2. Work with you to fix it
3. Credit you in the release notes (unless you prefer to stay anonymous)

Thank you for helping keep OpenPrivateDrive secure! 🙏
